## MiniDuck 从零训练与部署仿真

**作品 02 · 课程小组项目 · MuJoCo 3.6 仿真**

项目涵盖双足机器人步态训练、坡道配速与失稳恢复、封闭迷宫导航和终点动作。

- **10° 上下坡**：100 个独立试次全部通过，0 摔倒、0 碰撞，终点停稳用时中位数 52.46 秒。
- **封闭迷宫**：3/3 通过，每次完成 5°–10° 六段坡、终点停稳和 10 秒庆祝。
